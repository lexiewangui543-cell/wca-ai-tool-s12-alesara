WCA AI Study Buddy – Season 12

Project Overview

WCA AI Study Buddy is a Python-based learning assistant designed to help students understand academic topics, ask questions and receive AI-powered explanations.

Main Features

- Interactive conversations with an AI study assistant.
- Support for follow-up questions.
- Conversation memory.
- AI-generated study summaries.
- Saved conversation sessions.

Technologies

- Python
- Google Gemini AI
- Google GenAI SDK
- python-dotenv

Installation

1. Install Python.
2. Install the required packages using "pip install -r requirements.txt".
3. Create a ".env" file and add your Gemini API key.
4. Run the application using "python app.py".
